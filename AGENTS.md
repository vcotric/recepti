# Working instructions

This repository is a personal recipe collection. Keep it simple and readable on GitHub.

- Write recipes and reader-facing documentation in Serbian Latin script.
- Store each recipe in `recepti/<category>/<ascii-kebab-case-name>.md`.
- Use `sabloni/recept.md` as the starting format. Include quantities, numbered steps, approximate timing, variations, and cooking notes.
- Update the recipe table in `README.md` when adding or renaming a recipe.
- Use relative links for recipes and images. Put photographs in `slike/`.
- Mark new proposed recipes as `Za probu`. Do not claim they were tried without the owner's confirmation.
- Preserve personal cooking notes. Do not invent sources, nutrition values, or successful cooking results.
- Do not add a framework, database, build system, or website unless requested.
- Validate local Markdown links after changes. No automated test suite is needed for routine recipe edits.
- Publishing changes to GitHub requires authorization in the current task.
