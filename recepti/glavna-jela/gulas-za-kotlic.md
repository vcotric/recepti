# Gulaš za kotlić od 16 litara

| Podatak | Vrednost |
|---|---|
| Autor | Vlada |
| Kategorija | Glavna jela |
| Količina | Kotlić od 16 l; količina mesa za potvrdu |
| Ukupno vreme | Ukupno vreme nije navedeno |
| Status | Za probu |

Status probe nije potvrđen u razgovoru.

## Sastojci

| Sastojak | Količina |
|---|---|
| Svinjska plećka | „3 plećka svinja”, potvrditi da li 3 kg ili 3 komada |
| Juneći but | „3 but june”, potvrditi da li 3 kg ili 3 komada |
| Crni luk | 3 kg |
| Mast | 300 do 500 g |
| Šargarepa | 400 g |
| Domaći ajvar | 500 g |
| Paradajz pelat | 500 g |
| Suvi vrganj | 1 šaka |
| Šampinjoni | 1 pakovanje, krupno sečeni |
| Sušena ljuta paprika | 1 |
| Lovor | 2 do 3 lista |
| Čokolada za kuvanje | 2 do 3 reda |
| Aleva paprika | 2 supene kašike |
| Belo ili crno vino | 200 ml |
| Vegeta, so, biber | Po ukusu |
| Voda | Tek da prekrije meso |

## Priprema

1. Dobro prodinstaj luk na masti. Dodaj šargarepu i meso i nalij vodu samo da ogrezne.
2. Krčkaj na laganoj vatri. Vodu dolivaj samo koliko treba da prekrije meso.
3. Posle jednog sata dodaj začine, alevu i ostale sastojke, osim onih koje original ostavlja za kraj.
4. Pola sata pred kraj dodaj vino, paradajz i čokoladu. Ukupno vreme i kriterijum završetka nisu navedeni.

## Za dopunu

- Jedinica i ukupna masa mesa.
- Pelat je u sastojcima, a paradajz sok u postupku; potvrditi oblik.
- Veličina pakovanja šampinjona, priprema suvog vrganja i ukupno vreme kuvanja.
